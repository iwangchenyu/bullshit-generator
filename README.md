# AI 废话文章生成器

> 随机拼接生成长篇套话文章的经典开源工具，仅用于娱乐，请勿用于正规用途。

在线体验：https://wangchenyu.com/xiezuo/

## 功能特性

- 按主题与篇幅随机生成文章
- 段落随机拼接
- 一键复制结果

## 使用方法

1. 用浏览器直接打开 `index.html`，无需安装任何软件、无需构建、无需后端服务。
2. 所有计算与处理均在浏览器本地完成，数据不会上传到服务器。
3. 处理完成后使用页面上的复制 / 导出按钮即可保存结果。

## 技术栈

原生 JavaScript

## 目录结构

```
├── index.html        # 主页面
├── assets/ 或本地资源 # 样式、脚本与静态资源（按需）
```
